2. Recommended technology stack
Given your AWS, Linux, Docker and DevOps background, I recommend Python for the trading engine and Docker for deployment.

Component	        Technology	                      Purpose
Programming	        Python 3	                      Trading logic
Exchange API	        Binance / Alpaca	              Market connection
Data analysis	        Pandas, NumPy	                      Market analysis
Indicators	        TA-Lib / pandas-ta	              Trading signals
Strategy testing	Backtesting.py	                      Historical testing
Backend	                FastAPI	                              Bot management API
Database	        PostgreSQL	                      Trades and performance
Cache	                Redis	                              Fast data and state
Dashboard	        React	                              Monitoring interface
Deployment	        Docker	                              Containerization
CI/CD	                Github Actions	                      Automated deployment
Hosting	                Ubuntu VPS / AWS EC2	              24/7 execution
